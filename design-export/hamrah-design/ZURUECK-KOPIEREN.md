# So kommt das Design zurück

1. Lass Kimi die **vollständigen Dateien** schreiben (gleiche Namen wie hier).
2. Schick sie mir einfach hier in den Chat, oder lege sie in den Ordner `design-export/zurueck/`.
3. Ich vergleiche mit dem aktuellen Stand, prüfe, dass nichts Wichtiges fehlt (Texte, Links, Zugang), baue es ein,
   teste auf Handy und Computer und veröffentliche es.

Enthält dieses Paket Sicherheitscode? Nein. Keine Anmeldung, keine Datenbank, keine Schlüssel, keine Zahlungen, keine Server-Funktionen.
